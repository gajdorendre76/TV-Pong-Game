# TV Pong Game — International Edition (v1.8)

A retro Pong game built with Godot 4, with smartphone controllers over local Wi-Fi.

## Features
- Single player against the computer
- Two-player mode
- 2 vs 2 team mode with four independently controlled paddles
- Phone-based swipe controls, player names, and sensitivity settings
- Best-of-three rounds, 21 points per round
- Retro graphics, intro video, and music

## Run
Open `project.godot` with Godot 4 and run the project. Connect phones to the same local Wi-Fi network and use the displayed controller URL or QR code.
