# TV Pong Game — International Edition

A retro Pong arcade game built with **Godot 4** and controlled by phones over a local Wi-Fi network.

## Features
- Single player vs computer
- Two-player local multiplayer
- 2 vs 2 team matches with four independent paddles
- Smartphone browser controllers and QR-code pairing
- Player names and adjustable touch sensitivity
- Best-of-three rounds; each round plays to 21 points
- Retro TV visuals, intro video, music, and sound effects
- Automatic match pause on controller disconnection

## Run
1. Open `project.godot` in Godot 4.
2. Run the game.
3. Connect phones to the same Wi-Fi as the host PC and scan the QR code.
4. Enter your name and choose your player position.

## Project files
The Godot project and required assets are intended to be committed to this repository. At first publication, confirm that `main.gd`, `project.godot`, `controller.html` and the image, audio, and video assets are present before attempting to run.
